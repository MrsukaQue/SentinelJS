# Contributing

Thank you for improving SentinelJS. Open an issue before a large change, keep checks passive and non-destructive, and include a controlled fixture test for scanner behavior.

1. Create a focused branch.
2. Install dependencies and generate the Prisma client.
3. Make a small, documented change.
4. Run formatting, linting, unit tests, integration tests, and builds.
5. Open a pull request that explains security impact and test evidence.

Never add exploitation, credential attacks, authentication bypass, destructive requests, malware behavior, or scans against unapproved public systems. Do not commit response bodies, credentials, tokens, `.env`, or real user data.
